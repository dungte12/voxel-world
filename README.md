# Voxel World

A Java-based voxel world project developed by a team of four.

## Project Structure

- `core` - Application and game loop
- `world` - World and chunk management
- `terrain` - Terrain generation
- `block` - Block types and properties
- `entity` - Entities and player
- `renderer` - Rendering
- `util` - Utility classes

## Build

```bash
./gradlew build
```

## Run

```bash
./gradlew run
```
